# QuantumVPN 5.13.0 — интерфейс, измерения и Node Console

Тестовый prerelease, versionCode `501300099`, пакет `com.quantumvpn.debug` и прежняя подпись тестовых установок. Два локальных APK: ARM64 и ARMv7. Кнопки сценариев «Видео / Игры / Работа» не добавлены и их политика не изменена.

## Приложение

Обновлены главная с кнопкой подключения, визуальная тема, список серверов с виртуализацией полного списка, навигация, настройки и статистика. Скорость текущего трафика показывается только при активном потоке измерений; сохранённая история отделена от текущего показателя. Доступные действия сохраняются на компактном экране и при крупном системном шрифте.

Исправлен короткий тест скорости: DNS/TCP/TLS не включаются во время загрузки тела ответа, объём скачивания ограничен 32 МБ и восемью секундами; upload — 4 МиБ. Пустой ответ и отклонённый сервером upload не выдаются за успешный замер. Это измеряет путь телефона к тестовому узлу, а не пропускную способность всех сайтов или серверного speedtest.

В обезличенном diagnostic JSON теперь видны ограничения `up_mbps`/`down_mbps`, TLS/UDP fragmentation и её задержка, multiplex/TCP Fast Open и TUN stack. Удалены два вывода исключений в системный журнал.

## Дополнительная панель и ИИ

Отдельная авторизованная страница `/operator/server` использует существующий вход основного оператора. Показывает локальные измерения ресурсов, трафика, TCP congestion, очередь Linux, ограничители tc и реальные протоколы/порты из allowlist конфигураций Xray. Проверка TCP выполняется только к loopback-портам из конфигурации; экспорт не содержит клиентов, ключей и подписок. Управление протоколами и маршрутизацией ведёт в существующие рабочие разделы.

ИИ получает агрегированный итог собственного журнала: измеренные изменения, подтверждённые контрольными проверками решения и откаты. Старые, дублированные и неподтверждённые результаты не считаются успехом. Это обновление контекста и знаний, а не обучение весов модели; исполнение использует проверяемые действия существующего автопилота.

## Границы проверки скорости

Проверка VDS: BBR и fq включены; явных лимитов в двух активных Xray-конфигурациях не найдено, интерфейс и очередь не показывают потерь. Нагрузка сервера низкая. Эти наблюдения не доказывают отсутствие ограничений на пути телефона.

Телефон не подключён к ADB, его diagnostic JSON отсутствует. Исправление реального торможения YouTube и физические release-gates остаются открыты. Найдены кандидаты: сервис игнорирует выключенный `carrierBypassEnabled`, агрессивный режим перекрывает мягкий, adblock принудительно использует Maximum. VPN/TUN/DNS/core не изменены до обязательной системной и прикладной диагностики по проектному навыку.

Приложен `QuantumVPN-speed-evidence-collector.zip`: Windows-сборщик одной сессии без VPN/с VPN, logcat, connectivity/netd, CPU/потоков/памяти и явно экспортированного JSON. Сам скрипт не устанавливает APK, не очищает приложение и не меняет сети. Собранные приватные данные не публикуются в Releases.

## Верификация

262 модульных теста app/app-updater прошли, включая новый тест арифметики скорости и обезличивания диагностических полей. Инструментальные тесты скомпилированы; выполнение на устройстве не проведено. Node Console проверена Chrome на 1280 и 390 px, без ошибок JavaScript и горизонтального переполнения. Сборка Windows использует существующий безопасный SUBST helper и JDK 21. GitHub Actions остаются включённым независимым путём.

APK, per-APK SHA-256, `release-metadata.json` и `build-info.json` проверяются локальным packager перед публикацией; metadata содержит точный исходный commit и честный статус физических проверок.

Опубликовано: [v5.13.0](https://github.com/kayucm21/QuantumVPN/releases/tag/v5.13.0), source commit `aeb85812f58cd9ca8c807bf17ab5257e788bdf7a`. Подпись обеих APK совпала с предыдущими тестовыми сборками; `dirty_at_build=false`. Полная Python-проверка: 1168 тестов, 10 пропущено; последние 14 проверок Node/AI повторены после уточнения HTB. Проверка проекта и 9 отрицательных регрессий политики runtime прошли.

[Живая Quantum Node](https://pecaocek.ignorelist.com:8443/operator/server) развёрнута с резервной копией исходников. Авторизованные HTML/status маршруты вернули 200, найдено 9 записей портов, адрес ноды установлен; локальный llama.cpp успешно завершил анализ с обновлённым контекстом. Это подтверждает работу панели и адаптера, но не физический клиентский throughput.
