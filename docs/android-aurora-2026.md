# QuantumVPN 5.11.0 · Aurora 2026

## Изменения

- Единый мятно-синий фон с северным сиянием и статичными горами. Своя фотография
  применяется ко всему интерфейсу, декодируется в IO с ограничением 1440 px и
  не перечитывается при смене вкладок. Фото не отправляется в панель.
- Главная: крупная кнопка соединения, сервер, состояние DNS и рекламы, быстрый
  вход в «Дурак с друзьями». Четыре нижние вкладки и безопасный отступ сохранены.
- Серверы: поиск, фильтры реально доступных типов, полный ленивый список.
- Настройки: оформление, защита, сервис и отдельная доступность. Крупный текст
  сохраняет масштаб Android; высокий контраст, уменьшение анимации и виброотклик.
- Оформление: готовые стили, своя фотография, повторный выбор сохранённого фото.
- Запуск: настоящие состояния проверки; процент, МБ, скорость и время только
  для загрузки APK. Без выдуманного прогресса до 86%.
- Карты: скрытый код доступа (не saved-state), более крупные карты, прокрутка
  при открытой клавиатуре; запросы состояния прекращаются в фоне.
- Статичные фоны не создают бесконечную анимацию. Проверки видимых экранов
  приостанавливаются при скрытии Activity. Протоколы и VPN core не изменяются.
- Остатки APK/.part очищаются после ошибки/отмены, возврата установщика и на
  следующем старте процесса. Повторная попытка в рамках одной загрузки сохраняет
  промежуточные байты; успешная загрузка не запускается ещё дважды.

## Совместимость и выпуск

Версия `5.11.0`, versionCode `501100099` по `derive-release-version.sh v5.11.0`.
Этот код выше прежнего VDS 137 и прежних номеров опубликованных GitHub тегов.
APK сохраняет пакет `com.quantumvpn.debug` и существующий debug signer,
поскольку именно такие сборки уже раздавались панелью. Производственные и
тестовые подписи не подменяются.

Основной быстрый путь — локальные arm64-v8a и armeabi-v7a, SHA-256 и metadata
в отдельном GitHub prerelease. GitHub Actions не отключаются. APK-проверки не
доказывают реальный VPN, плавность на телефоне или доставку уведомления каждому.

ADB на момент начала задачи не обнаружил устройств; эмулятор SDK отсутствует.
Системный logcat/diagnostic и замеры кадров на физическом телефоне пока получить
нельзя. Публикация сборки не закрывает проверку плавности и VPN на физическом
устройстве. Существующие клиенты и ключи на VDS не удаляются.

## Проверки

- `app:testDebugUnitTest`: 204 теста, 0 ошибок.
- `app-updater:testDebugUnitTest`: 17 тестов, 0 ошибок.
- `app:compileDebugAndroidTestKotlin`: успешно. Android-тесты не запускались:
  ADB не видит устройства. Добавлены тесты реальных кнопок, запуска без ложного
  процента и однократной успешной загрузки.
- Оба локальных APK проверяются `aapt2`/`apksigner`, набором native ABI и SHA-256.
  Пакет и сертификат совпадают с отдельно скачанной живой версией VDS 5.10.12.
- Общий `verify-project.sh` остановился на старом несоответствии копии `NOTICE`
  в raw-ресурсах; его прохождение не заявляется, проверки не ослабляются.
- Публикация на VDS отделена от загрузки: `deploy-local-apk-release.py` сначала
  проверяет оба APK, затем с `--promote` атомарно меняет версию и сигнал обновления.
  Перед изменением сохраняется БД. Старые релизы и клиентские ключи не удаляются.
  Уведомление появляется после обновления политики при наличии разрешения Android.
  Создание сигнала не доказывает получение всеми устройствами.
