# Quantum Node

Дополнительная панель доступна после входа в Quantum Control по `/operator/server` и `/operator?tab=server`. Она использует существующую сессию и роли основной панели. Ссылка находится в группе «Сеть».

Панель сопоставляет входящие протоколы и порты из `/var/lib/rospanel/xray/config.json` и `/etc/quantumvpn-reserve/xray.json` со слушающими TCP/UDP-сокетами Linux. UUID, пароли, ключи, клиенты, имена профилей и полный конфиг не попадают в HTML или JSON. Файлы можно выбрать только в окружении сервиса через `QV_NODE_XRAY_CONFIG` и `QV_NODE_RESERVE_CONFIG`; HTTP-запросы их не задают. Адрес сервера задаётся через `QV_NODE_PUBLIC_ADDRESS`, иначе интерфейс показывает отсутствие данных об адресе.

«Обновить данные» читает `/operator/server/status`. Снимок кешируется на 5 секунд. Нагрузка CPU — средняя нагрузка за минуту, нормированная на число ядер; это не мгновенное использование CPU. RAM рассчитывается по MemAvailable, диск — по корневой файловой системе. Приём/передача — разница байтов всех интерфейсов кроме loopback между последовательными снимками. Первый снимок, сброс счётчика, изменение числа интерфейсов или пауза больше 120 секунд оставляют скорость неизвестной. Это нагрузка интерфейсов, а не измеренная скорость VPN.

TCP congestion control берётся из `/proc/sys/net/ipv4/tcp_congestion_control`. Очереди и явные верхние границы скорости читаются через фиксированные `tc -j qdisc show` и `tc -j class show`. Числа JSON в iproute2 выражены в байтах/с, поэтому перед отображением умножаются на 8. Для HTB учитывается ceil: rate является гарантированной полосой и допускает заимствование, поэтому не объявляется верхней границей. [Исходник iproute2: формат JSON rate](https://github.com/iproute2/iproute2/blob/main/lib/json_print.c), [семантика HTB rate/ceil](https://github.com/iproute2/iproute2/blob/main/tc/q_htb.c). Неизвестные дисциплины, HFSC service curves и недоступные данные оставляют вывод о лимитах неизвестным.

«Проверить порты» вызывает `/operator/server/diagnostics`: только owner/operator, точный Origin, CSRF текущей сессии, ограниченный размер и частота запроса. Проверяются только TCP-порты локальной конфигурации на 127.0.0.1/::1 с таймаутом 150 мс. UDP, TLS-согласование, внешний firewall и путь телефона эта проверка не подтверждает. В аудит записываются количество портов и перечислимые причины. Команды, адреса и параметры конфигурации не принимаются. Кнопки управления протоколами и маршрутами ведут к действующим разделам основной панели.

«Скачать отчёт» экспортирует текущий санитизированный снимок JSON. Протоколы, порты и настройки сервера эта версия страницы не переписывает.

ИИ получает новую агрегированную память из последних 100 записей журнала за 7 дней: измеренные применённые изменения, отдельные подтверждения после проверки, откаты и ручные отмены. Будущие/старые записи, повторные записи, предложения без применения и недостаточные серии проверок не увеличивают число подтверждённых результатов. Это контекст анализа; веса модели не обучаются, полномочия исполнителя не расширяются. Внешний и локальный адаптеры получают только числовые счётчики. Дополнены фиксированные правила сравнения direct/VPN на одном телефоне и сети, проверки MTU, потерь, retransmit, нагрузки и tc.

Для безопасного развёртывания новой страницы используйте `tools/deploy-aurora-panel.py --with-node-console` с существующими pin/hash-параметрами. Новая установка ожидает отсутствие `quantumvpn_node_console.py`; при обновлении передайте `--expected-old-node-console-sha256`. Обновление знаний и памяти требует обычных соответствующих scopes для AI knowledge/journal/Gemini/llama с проверенными старым SHA-256. Откат развёртывания восстанавливает только исходники.

Офлайн-проверки: `python -m unittest tools.test_node_console tools.test_ai_learning tools.test_ai_knowledge tools.test_aurora_panel tools.test_deploy_aurora_panel tools.test_gemini_advisor tools.test_llama_autopilot tools.test_operator_panel`. Для существующих тестов автопилота каталог `tools` должен быть в PYTHONPATH; альтернативно запускайте `python -m unittest discover -s tools -p 'test_*.py'`.
