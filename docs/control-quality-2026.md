# Quantum Control: контроль качества и будущий интерфейс

Обновлена только дополнительная панель, сборка `5.10.12-control.1`.
Android APK, `versionName`, `versionCode` и расписание публикации не изменялись.

## Реализовано в панели

- Один раздел «Контроль качества» вместо отдельных вкладок для каждой проверки.
- Инспекция последнего ответа подписки: формат, количество серверов по протоколу,
  SHA-256, неизвестные схемы и предупреждение о включённом, но отсутствующем AWG.
  Ссылки профилей, ключи и HWID не включаются в отчёт.
- Ручная инспекция использует уже зарегистрированный Android HWID только для
  пользователя, чей токен совпадает с настроенным upstream. Новых привязок нет;
  при отказе основной панели предыдущий успешный отчёт сохраняется.
- Объяснение опубликованного маршрута для домена/IP/URL. URL не открывается.
  Приоритеты сопоставлены с `RoutingConfigEditor`: block → direct → LAN/RU → proxy.
  Локальный RU-список и оставшиеся правила телефона не выдаются за проверенные.
  Семантика непубличных IP сверена с [документацией sing-box](https://sing-box.sagernet.org/configuration/route/rule/#ip_is_private).
- Карта зависимостей берётся из реальной базы RosPanel: нода → inbound/порт →
  общая выдача → число включённых пользователей. Индивидуальная выдача может отличаться.
- История доступности за 24 часа с временем замера. Проверки служб не отображаются
  как выдуманный нулевой пинг; измерения VDS не равны задержке VPN на телефоне.
- Запросы политики/обновления учитываются только при наличии идентификатора
  устройства. Сообщённая версия не равна независимому подтверждению установки.
  Старые APK не передают разрешение уведомлений, факт показа, загрузки и установки:
  эти поля остаются неизвестными, а не фиктивно успешными.
- Сохраняются рекомендации Qwen, агрегированный снимок входных измерений и ответ
  Telegram API. У Qwen нет выполнения команд; история хранится 30 дней.
- Проверка AES-GCM, ZIP и восстановления обеих SQLite-баз в закрытом временном
  каталоге. Рабочие базы не заменяются. Новые шифрованные архивы включают файлы
  сессии, ключ подписания маршрутизации, секрет RosPanel и его сертификат/ключ.
  Серверные программы, окружение и внешний AES-ключ нужны отдельно для полного запуска.

## Проверка

```powershell
python -m unittest tools.test_control_quality tools.test_operator_panel
git diff --check
```

44 теста: приоритеты правил, неизвестная телеметрия, запрет записи viewer,
сохранение вкладки, недоступный upstream, выбор существующей Android-привязки,
отсутствие секретов в отчётах, проверка архива, неверный ключ/тег, схема SQLite,
защита от ZIP path traversal и отсутствие plaintext после ошибки шифрования.

VDS: HTTPS `/operator?tab=quality`, `/status`, `/api/client/routing` проверены.
Действия инспекции, объяснения маршрута и проверки архива возвращаются в `quality`.
Восстановление новой копии обеих баз прошло; все перечисленные ключевые файлы
присутствуют, зашифрованный файл имеет права `0600`.
Деплой сохраняет предыдущий код и не перезапускает RosPanel/Xray.
Визуальная проверка: основные блоки раздела помещаются на экране высотой 720 px;
при ширине 390 px нет горизонтального переполнения страницы. Раскрытие подробных
таблиц может потребовать прокрутки внутри блока.

### Итоговый набор промптов

Общее: high-fidelity Android UI mockup для будущего QuantumVPN 2026, фронтальный
вид полноценных телефонов; русский текст, оригинальный cyan Q, тёмно-синий фон,
северное сияние над горным озером, полупрозрачные карточки, mint/cyan действия и
violet акценты. Крупные читаемые подписи, практические touch targets 48dp,
никаких обрезанных элементов; нижняя навигация «Главная / Серверы / Статистика /
Настройки» отделена от жестовой полоски Android. Без водяных знаков, рекламы и
ИИ-помощника. Показатели — примеры для макета, не обещание производительности.

- Доска 1: три телефона рядом. Запуск с Q и «QuantumVPN», checklist сети/серверов,
  загрузка обновления 64%, 82/128 МБ, около 12 секунд, последующий системный
  установщик Android. Приветствие «С возвращением!», безопасность, друзья/игры,
  оформление, запрос уведомлений с «Разрешить уведомления / Позже», «Продолжить».
  Главная «Привет, Алексей», круглая кнопка «Подключиться», состояние «VPN выключен»,
  выбранный сервер с 48 мс, подписка на 24 дня, «Дурак с друзьями» / «Открыть игру».
- Доска 2: четыре телефона, сетка 2×2. Серверы с поиском и «Все / Основные / Резерв»,
  VLESS XHTTP 48 мс, Hysteria2 52 мс, AWG 2.0 61 мс, TURN «Проверка», независимое
  обновление пинга, «Выбрать сервер». Статистика 2,48 ГБ, график, загрузка/отдача,
  время сессии и задержка. Игровая комната с виртуальными Q-coins, друзьями
  СеверныйЛис/ЛуннаяПанда, приглашениями, «Создать комнату / Войти по коду», ожиданием
  Q7F2. Стол с классическими картами, козырем, колодой, ходом, «Взять / Бить» и чатом.
  Балансы виртуальные, не деньги, без вывода и без реальных платежей.
- Доска 3: три телефона рядом. Настройки сгруппированы в «Соединение / Безопасность /
  Оформление / Доступность», уведомления и диагностику. Оформление: «Сияние / Город /
  Мой фон», фото из галереи, предпросмотр главной, затемнение 40%, размытие 20%,
  пузырьки при нажатии и сохранение. Доступность: размер текста, высокий контраст,
  уменьшение движения, виброотклик, пример крупного интерфейса, фокус и TalkBack.

Эти изображения не подтверждают наличие функций в установленном APK. Реальная
оптимизация анимаций, памяти и кадрового времени требует отдельной реализации
и проверки на устройствах по Android-навыку проекта.
