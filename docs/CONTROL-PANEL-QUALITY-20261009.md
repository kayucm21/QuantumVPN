# Дополнительная панель: качество и доменные ссылки

Область изменения: только дополнительная панель. APK, Android-лаунчер,
бот, модели, ключи прокси, VPN-сервисы, маршруты и расписание выпуска не меняются.

## Telegram

Владелец запрашивает ссылки явным POST с Origin/CSRF-проверкой. Панель показывает
фиксированный `pecaocek.ignorelist.com` вместо числового адреса:

- MTProto: реальный порт 3443, прежний padded-ключ.
- MTProto TLS: реальный порт 5443, прежний FakeTLS-ключ с доменом.
- WEB Proxy: прежний домен/приватный путь и HTTPS 443.

Маппинг выполняется только для собственных известных endpoints. Чужой IP/порт
не может стать доверенной доменной ссылкой. Пинованные runtime-контракты прокси
сохраняются. Ключей нет в обычном GET, журналах и результатах проверки;
ответ владельцу — `no-store`, `no-referrer`. Копирование и открытие остаются
явными действиями. Домен не скрывает публичный IP от DNS; порт обязателен.

## Качество

Раздел «Качество» отделяет добровольные клиентские самоотчёты от замеров VDS.
Группы: непрозрачный ID ноды, протокол и тип сети. В сводке нет устройств,
IP клиентов, посещённых сайтов или искусственных географических точек.
Недостаток измерений не превращается в нулевой пинг или утверждение о ТСПУ.
Это наблюдение, не автоматическое переключение клиентов.

Проверка восстановления резервной копии уже доступна в этом разделе:
AES-GCM, ZIP, восстановление SQLite в отдельном временном каталоге.
Она не заменяет рабочие базы и не доказывает запуск всей инфраструктуры.
Отсутствующие серверные файлы показываются отдельно. Для физического резерва
нужен действительно другой сервер, не второй протокол на том же VDS.

## Проверка и развёртывание

`tools/deploy-aurora-panel.py --with-quality --with-pulse` использует ожидаемые
старые SHA-256, резервирует прежние исходники, проверяет настройки/ключ подписи,
API обеих ARM ABI и откатывает исходники при неуспехе. Перезапускается только
дополнительная панель, не основной VPN.

`tools/verify-network-pulse.py --require-mtproto` проверяет страницы, CSRF,
production API и HTTPS HEAD опубликованных APK. `tools/verify-panel-domain-links.py`
дополнительно выполняет owner-POST показа трёх ссылок и WEB health proof.
Он проверяет домен, порты, совпадение пар, no-store и кнопки; секреты остаются
в памяти VDS. Команд stop/start/restart в этой проверке нет.

Это серверные/HTTP-проверки. Работа кнопок в настоящем Telegram клиента,
пинг конкретного оператора и пользовательский буфер обмена ими не подтверждены.
